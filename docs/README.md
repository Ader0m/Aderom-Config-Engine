# ACE — документация

Дата: 26.11.2026.

Это единственная точка входа в документацию ACE. Здесь описаны карта
документов, текущее состояние и ссылки на инструкции для AI-агента.

## 1. Карта документов

| Документ | Назначение |
|---|---|
| `docs/README.md` | Карта, текущий режим, ссылки на инструкции для AI |
| `docs/Целевая архитектура приложения.md` | Целевая архитектура, инварианты, ADR |
| `docs/Целевая архитектура модулей.md` | Контракт модулей, lifecycle, capabilities, SDK |
| `docs/Инструкция для нейросети — работа с приложением.md` | Слои, запреты, операции, кэш, патчи, тесты, stop-условия |
| `docs/Инструкция для нейросети — создание модулей.md` | Манифест, lifecycle, capabilities, ответственность модуля |
| `docs/Верификация движка X-Ray_ От C++ к Python — как воспроизвести идентичную логику генерации конфигураций без запуска игры.pdf` | Справочная верификация движка |
| `docs/Карта горячих клавишь.txt` | Пользовательские горячие клавиши |

`AGENTS.md` в корне — постоянный контракт для AI-агента и людей.

Исторические документы, старые ADR, baseline и журнал миграции находятся
в `archive/docs/` и `baseline/` **вне** `docs/`. Они сохранены для
контекста, но **не являются источником правил**. Актуальная
документация не должна противоречить коду и ADR, интегрированным в
`docs/Целевая архитектура приложения.md`.

## 2. Текущий режим

| Параметр | Значение |
|---|---|
| Режим | **migration / guardrails** |
| Этапы 0–7 | завершены |
| Этап 8 | 8.1–8.2, 8.4–8.6 выполнены; **8.3 (19023/19024) открыт**; боевой release gate не объявлен |
| Этап 9 | 9.1–9.6 выполнены; поколенческая очистка кэша остаётся отдельным пунктом |
| Проверка | **1386 passed, 1 skipped, 76 subtests**; `compileall` и `git diff --check` чистые |
| SDK | `0.14.0`; публичный набор — `sdk.__all__` по allowlist |
| Запись патчей | **экспериментальная**: `PATCH_WRITE_EXPERIMENTAL=True` (ADR-37); откат — `False`; паритет 19023/19024 не подтверждён |
| Данные проекта | схема `2`; one-time forward migration с backup |
| Кэш | `generated/cache-v2/*`; старый кэш не читается и удаляется при старте |
| Снимок VFS | `WorkspaceSession.snapshot_id`; смена overlay — новая ревизия |

### Открытые пункты

- 8.3: 19023/19024 не локализовано; нужен игровой дамп.
- Поколенческая очистка дискового кэша.
- GAP-6: ручная очистка `.migration_backup_*`.
- `ARCH-FALLBACK`: остатки `getattr(..., "method", None)` вне SDK-мостов.
- Legacy-конструкторы `cache`/`resolved_cache` — test-only; полное
  удаление отдельным решением.

### Legacy-карантин

Активных критических и слойных исключений **нет**.
`UI_CORE_IMPORT_ALLOWLIST` пуст; прямые импорты `core` из `ui` запрещены.
`ogg_editor.requires base` — намеренная зависимость ADR-35, а не
исключение. Legacy-конструкторы `cache`/`resolved_cache` используются
только в standalone/тестах; production работает через `cache_service`.
Полный список закрытых исключений — в `archive/docs/history/Миграционные исключения.md`.
