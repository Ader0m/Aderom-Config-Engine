# Документация ACE

Короткая карта документов. Если документ противоречит `AGENTS.md` или
целевой архитектуре — прав `AGENTS.md` и целевой документ.

## Актуальные документы

| Документ | Назначение |
|---|---|
| `AGENTS.md` | Постоянные правила для AI-агента и людей |
| `docs/Целевая архитектура приложения.md` | Целевая архитектура приложения |
| `docs/Целевая архитектура модулей.md` | Целевой контракт модулей |
| `docs/План перехода к целевой архитектуре.md` | Этапы миграции |
| `docs/Текущий режим.md` | Текущий этап, запреты и gaps |
| `docs/Миграционные исключения.md` | Legacy-карантин |
| `docs/adr/README.md` | ADR и шаблон решений |
| `docs/Performance baseline.md` | Точка сравнения производительности Этапа 0 |
| `docs/baseline/stage0.json` | Машиночитаемый снимок baseline |
| `docs/baseline/stage0-manifest.json` | Эталонный набор секций, ключей, файлов и корней |
| `docs/Обнаруженые проблемы.md` | Текущий аудит проблем |
| `docs/main_unit_tests.md` | Правила приёмочных тестов |

| `docs/Верификация движка X-Ray...pdf` | Справочный материал по движку |

## Архив

`docs/old/` — исторические и заменённые документы. Они сохранены для
контекста, но **не являются источником правил**.

Подробности — `docs/old/README.md`.

## Порядок чтения для агента

1. `AGENTS.md`.
2. `docs/Текущий режим.md`.
3. `docs/Миграционные исключения.md`.
4. Целевой документ слоя.
5. Соответствующий этап плана миграции.
6. ADR, если решение уже принималось.

Не читай `docs/old/` как инструкцию. Если нужен исторический контекст —
читай, но не используй как аргумент.
