# ADR-36. Уверенность связей графа

Дата: 25.11.2026
Статус: accepted

## Контекст

Граф связей секции различает типы рёбер (`declaration`, `inheritance`,
`ltx_reference`, `script_reference`, `xml_reference`,
`texture_reference`, `visual_reference`), но не показывает, насколько
связь доказана. Целевая архитектура требует для каждой связи уровень
уверенности `exact/probable/heuristic` и явное отображение в UI.

`CACHE-5` в миграционном карантине фиксировал отсутствие `confidence`.
Кэш графа был закрыт шагом 7.9; этот ADR закрывает вторую часть —
модель и отображение уверенности.

## Решение

1. В `MatchInfo` (core) добавлено поле `confidence`.
   Если оно не задано, значение выводится из типа ребра:

   | Тип | Уверенность |
   |---|---|
   | `declaration` | `exact` |
   | `inheritance` | `exact` |
   | `texture_reference` | `exact` |
   | `visual_reference` | `exact` |
   | `ltx_reference` | `probable` |
   | `xml_reference` | `probable` |
   | `script_reference` | `heuristic` |

   `exact` означает явную синтаксическую связь, `probable` — найденное
   упоминание без полного разбора, `heuristic` — эвристический поиск в
   коде.

2. В публичный SDK `GraphMatch` добавлено обязательное
   keyword-only поле `confidence: str`. Значения по умолчанию нет:
   модуль, создающий связь, обязан явно указать `exact`, `probable` или
   `heuristic`. Встроенный `ogg_editor` передаёт `exact` для явных
   ссылок на звук.

3. `GraphNode.primary_confidence` возвращает уверенность основной
   связи. UI графа показывает отдельную колонку «Уверенность»:
   `Точная`, `Вероятная`, `Эвристика`; неизвестное значение выводится
   как есть.

4. Core -> SDK conversion (`_to_section_graph_view`) передаёт
   `confidence` без потери.

5. Версия SDK повышается до `0.13.0` по ADR-11 (pre-1.0). Поле
   обязательное, поэтому для ручных конструкторов `GraphMatch` это
   breaking change; все встроенные модули/тесты обновлены в том же
   изменении.

## Альтернативы

1. **Хранить уверенность только в UI.** Отклонено: модули и будущие
   потребители графа должны получать её из контракта, а не угадывать.
2. **Сделать все связи `exact`.** Отклонено: скриптовый поиск и
   текстовые упоминания не доказывают связь.
3. **Оставить default `exact` для совместимости.** Отклонено:
   внешних модулей нет, ADR-11 прямо разрешает ломать контракт до
   `1.0`, а default `exact` завышал бы уверенность неизвестных связей.
   Поле сделано обязательным keyword-only.

## Последствия

- Публичная модель SDK расширена; версия `0.13.0`.
- Конструкторы `GraphMatch` требуют `confidence`; встроенные модули и
  тесты обновлены; сортировка/фильтрация графа не меняется.
- Появляется единая точка правил `edge_confidence` в core.
- Тест полноты требует, чтобы каждый `EdgeType` был в
  `_EDGE_CONFIDENCE`; неизвестный тип не остаётся незамеченным.
- `CACHE-5` можно закрыть: graph-кэш и confidence реализованы.

## Срок и условия выхода

Правила уверенности действуют до появления новых типов рёбер. Новый тип
обязан получить значение в `_EDGE_CONFIDENCE` и тест. После `1.0`
изменение поля идёт по semver/deprecation-политике.
