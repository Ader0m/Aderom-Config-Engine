# Тесты `main_unit_test_*`

Файлы тестов, имена которых начинаются с `main_unit_test_`, являются
эталонными (приёмочными) тестами проекта. Они фиксируют согласованное с
оператором поведение и служат контрактом для остальной кодовой базы.

## Правила

1. **Создание — только по команде оператора.**
   Тест `main_unit_test_*` запрещено создавать без явной команды оператора.

2. **Изменение — только с положительным откликом оператора.**
   Тест `main_unit_test_*` запрещено изменять без положительного отклика
   (одобрения) оператора. Причина изменения должна быть подробно описана,
   а сами изменения применяются только после одобрения оператора.

## Порядок изменения

1. Описать, что именно и почему нужно изменить в тесте.
2. Дождаться положительного отклика оператора.
3. Внести изменения.
4. Убедиться, что тест проходит (или что его падение ожидаемо и
   согласовано с оператором).
