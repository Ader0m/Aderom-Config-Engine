Modules
Модули могут:
регистрировать меню;
регистрировать сортировки/фильтры дерева;
регистрировать окна и панели;
менять размер окон;
задавать их якорь;
откреплять их;
управлять их состоянием;
отправлять команды;
свободно работать с данными внутри своих окон.
SDK
стабильный публичный интерфейс для модулей;
единая точка импорта;
скрывает внутренние реализации.
UI
отображение дерева файлов;
текстовый редактор;
открытие файла в окне;
возможность переопределить, где откроется файл;
фабрика/инструмент создания окон;
выполнение визуальных команд.
Core
TreeBuilder — дерево зависимостей файлов, по умолчанию без фильтров;
TreeQueryService — выдача дерева с фильтрами по запросу модулей;
LTXResolver — внешний инструмент, подключенный через адаптер; (Файл Resolver4.py)
PatchPlanner — «Сохранить как», планирование патча;
DLTX/DXML generators — «Сохранить», генерация дельты;
FileCacheSystem — кэш файлов, распарсенных данных и деревьев.
ReferenceGraphBuilder - где используется секция/идентификатор; какие ключи на нее ссылаются; какие секции от нее наследуются; какие файлы/патчи с ней связаны; выдачу обратных ссылок для UI.

ядро дает дерево, резолв, кэш и генерацию патчей;
UI дает платформу окон, редактор и дерево файлов;
модули получают свободу в своих окнах и могут управлять ими почти полностью;
SDK защищает приложение от хаотичных изменений из модулей.
