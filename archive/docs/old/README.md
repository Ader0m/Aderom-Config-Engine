# Архив документации

Здесь лежат исторические и заменённые документы. Они сохранены для
контекста, но **не являются источником правил** для AI-агента или
разработки.

Актуальные документы:

- `AGENTS.md`;
- `docs/README.md`;
- `docs/Целевая архитектура приложения.md`;
- `docs/Целевая архитектура модулей.md`;
- `docs/Инструкция для нейросети — работа с приложением.md`;
- `docs/Инструкция для нейросети — создание модулей.md`;
- `docs/Верификация движка X-Ray_ ...pdf`;
- `docs/Карта горячих клавишь.txt`;
- `src/modules/README.md`.

## Что здесь лежит

| Документ | Почему в архиве |
|---|---|
| `Архитектура программы.md` | Теоретическая редакция от 04.11.2026; заменена целевой архитектурой |
| `Архитектура программы.txt` | Исходный замысел; содержит устаревшие статусы и планы |
| `План архитектуры приложения сокращенный.txt` | Исходный краткий план; заменён целевой архитектурой |
| `modules_architecture.md` | Фактический контракт на момент миграции; заменён `docs/Целевая архитектура модулей.md` и текущим режимом |
| `История миграции ACE.md` | Подробный журнал этапов 0–9 до 26.11.2026; текущее состояние — в `docs/README.md` |
| `ОТЧЕТ_архитектура_системы_подсказок.md` | Проектный отчёт/черновик; актуальная реализация и правила — в коде и целевых документах |

## Правило

Если документ противоречит `AGENTS.md` или целевым документам — прав
`AGENTS.md` и целевой документ. Архив не используется как аргумент.
