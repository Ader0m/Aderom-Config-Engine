# item_browser

Модуль UI для просмотра предметов. Доменная сборка каталога, иконки и
локализация принадлежат `app/features/items`; модуль владеет только UI
каталога, карточек и drag-and-drop.

## Возможности

Предоставляет:

- `items.catalog` — каталог предметов и карточка предмета;
- `item.section.dragdrop` — MIME-контракт и приём предметной секции.

Модуль можно отключить через `config/modules.json`; базовые LTX/XML
возможности от него не зависят.

## Манифест

- `id`: `item_browser`
- `sdk.min`: `0.14.0`
- `requires`: нет
- `needs`: нет
- `enabled_by_default`: `true`
- `trust`: `trusted` (принимается только для id из `SHIPPED_MODULE_IDS`)

## Границы

- Домен и правила создания предмета — `app/features/items`, не в модуле
  и не в `core`.
- Модуль не импортирует `core`, `app`, `ui` и другие модули.
- Тяжёлая сборка каталога и иконок выполняется через `ctx.tasks`.
- Изменения предмета идут через проектные документы и патч-конвейер,
  а не прямой записью в оригиналы.
